# Horcrux

A Go project initialized for future development.

## Setup

1. Run `./init.sh` to set up the project.
2. Build the project with `go build`.
3. Run the binary with `./horcrux`.

## Project Structure

- `main.go`: Entry point of the application.
- `internal/`: Internal project structure.
- `go.mod`: Go module file.
- `go.sum`: Go dependencies checksum file.
